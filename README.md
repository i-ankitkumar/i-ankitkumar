### Featured — [kittybot](https://github.com/i-ankitkumar/kittybot)

**Split household expenses from Telegram.** Pulls grocery orders from Swiggy Instamart, Zepto, Blinkit and BigBasket and writes the shared expenses to [Kittysplit](https://kittysplit.com) — but only after you approve every split.

The hard part is not the arithmetic, it is that a ₹1,248 order might be entirely yours, entirely your flatmate's, or split 70/30. No rule can tell those apart, so the bot asks, every time.
